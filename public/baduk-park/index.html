함께 두는 바둑

설정은 ‘새 대국’부터 적용됩니다. 무르기는 연습용 합의 기능이며 정식 대회 권리가 아닙니다. 새로고침 시 기록이 사라지므로 기보를 내려받으세요.

이전 판 모양이 반복되었습니다. 장생·삼패·순환패의 성립을 자동 증명하지 않습니다. 양측이 실제 장기 반복임을 확인한 경우에만 합의하세요. 한국은 무승부, 일본은 승패 없는 무효 대국(無勝負)으로 기록됩니다. 사용자 변형의 중국 단순패도 합의 시 무효 대국으로 처리합니다.

계가 검토 · 아직 결과가 아닙니다

사활은 자동 판정하지 않습니다. 양측이 합의한 사석·빅을 지정하고, 미완성 경계·공배를 확인하세요. 표시를 바꾸면 양측 확인이 취소됩니다.

집 계가에서 빅 돌에 접한 빈 영역은 제외합니다. 면적 계가에서는 빅 돌과 그 한쪽 색만 둘러싼 빈 점도 셉니다. ‘빈 영역 제외’는 합의된 공배·미정 영역 전체에 적용됩니다.

재개 선착을 직접 합의해야 합니다. 일본은 재개 요청 상대방이 선착, 중국 사활 분쟁은 사석이라고 주장한 측이 선착입니다. 한국의 부분 사활 확인과 일본의 가상 사활 확인은 지원하지 않아, 재개 착수는 실제 판·잡은 돌·기보에 반영됩니다. 집 계가 점수가 달라질 수 있으므로 정식 분쟁 판정 대용으로 쓰지 마세요.

착수 기록

    규칙과 지원 범위

    각국 규칙을 바탕으로 구현한 로컬 연습 대국입니다. 모든 정식 판례·대회 운영 규정의 완전한 구현은 아닙니다. 모든 설정에서 자살수는 금지하고, 상대 돌을 먼저 제거한 후 활로를 검사합니다.

    기본 프리셋 (호선)
    규칙백 덤계가반복
    한국6.5집집 + 포로 + 합의된 사석 / 빅 집 제외단순패 + 장기 반복 양측 합의 무승부
    일본6.5집집 + 포로 + 합의된 사석 / 빅 집 제외단순패 + 장기 반복 양측 합의 무효 대국(無勝負)
    중국7.5점살아 있는 돌 + 둘러싼 빈 점 (포로 가산 없음)PSK: 이전 전체 판 모양의 재현 금지
    • PSK는 판 모양만, SSK는 판 모양과 다음 차례를 비교합니다. 초기 빈 판과 패스 후 국면도 비교 이력에 포함하고, 패스 자체는 반복 검사에서 면제합니다. 두 번 연속 패스하면 계가 검토로 전환합니다.
    • 한국·일본에 PSK/SSK를 선택하거나 중국에 다른 반복 규칙을 선택하면 사용자 변형입니다. 중국은 2002 규칙의 전체 동형 반복 금지 원칙을 PSK로 적용하며 대회별 예외 재대국·무승부 판정은 지원하지 않습니다.
    • 사석은 무리 전체를 지정하고 포로에 한 번만 더합니다. 공배는 양쪽 경계인 빈 영역을 자동 제외합니다. 한쪽 색만 경계인 영역은 집 후보일 뿐, 살아 있음의 증명이 아닙니다. 미완성 판에서는 자동 계산을 결과로 믿지 마세요.
    • 빅·귀곡사·장생·삼패·순환패·쌍패 및 일본 1989 사활 확인의 패별 착수포기·가상 진행을 자동 판정하지 않습니다. 빅은 관련된 모든 무리를 양측 합의로 직접 표시해야 합니다. 미합의 사활은 확정하지 마세요.
    • 중국 결과는 양측 면적 차이의 점 단위입니다. 중국식 단일 측 계가의 자(子) 단위 승차는 여기 표시된 승차의 절반입니다. 공유 공배를 양측 반씩 더해도 차이는 같으므로 화면 합계에는 공배를 더하지 않습니다.
    • 9·13줄은 연습판이며 덤은 19줄 기본값을 유지합니다. 대회 공인 소형판 덤으로 주장하지 않습니다. 덤은 0.5 단위로 조정 가능하며 0덤 동점은 지고(持碁)입니다.
    • 접바둑·덤 자동 산정·시간제/초읽기·반칙패·양측 패배 심판·AI·온라인 대전·기보 불러오기는 지원하지 않습니다. 기권과 최종 계가 후에는 착수를 막으며, 연습용 무르기는 종료도 되돌릴 수 있습니다.
